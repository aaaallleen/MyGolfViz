# FlightScope fixtures

Three real FlightScope Mevo Gen 2 exports (`*.csv`). File names are untrusted labels and carry no meaning.

`expected/<file name without .csv>.expected.json` holds the golden expectations for each export. They were written by hand from the CSV text, not generated by a parser. Both the TypeScript parser (`@fsa/csv-parser`) and a future Python parser must reproduce them.

## Format

| Key | Meaning |
|---|---|
| `file` | CSV file name in this folder |
| `sha256` | SHA-256 (hex) of the raw file bytes |
| `parserVersion` | Parser version the expectations were written for |
| `columnCount` | Number of header cells |
| `shotCount` | Number of shot rows (Avg/Dev rows excluded) |
| `summaryRowCount`, `summaryRows` | Avg/Dev rows with `club`, `kind` (`Avg` or `Dev`) and `sourceRow` |
| `clubs` | Shot count per club name |
| `nonNullCounts` | Number of shots with a non-null value for the given measurement key |
| `missingColumns`, `unrecognizedColumns` | Measurement keys absent from the file; header texts not recognized |
| `flags` | For each quality flag, the `sourceRow` of every flagged shot |
| `shots` | Spot-checked shots: `sourceRow`, `shotLabel`, `club`, `shotType`, `mode`, `location`, and `m` |

Rules:

- `sourceRow` is the 1-based record number; the header is record 1. Blank records are counted.
- `m` lists only the measurement keys being asserted, except for the first shot of `Sept 19 2022`, which lists all 27. Numbers are compared to 6 decimals. `null` means blank, `-` or `N/A`, never zero.
- Units are canonical: mph, yd, rpm, ft, in, deg, s. Left values are negative (`6 L` is `-6`). Low point is in inches.
- A text value of `-`, blank or `N/A` is `null`.
